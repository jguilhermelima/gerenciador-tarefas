<h1 align="center"> Gerrenciador de Tarefas </h1>

<h2>Descrição do Projeto</h2>
Este projeto tem como funcionalidade criar um gerenciador de tarefas.  

Utilizando uma interface RESTful para comunicação e flask SQLALchemy para criação de banco de dados.
O projeto tem funcionalidades como criar tarefa, editar tarefa e excluir tarefa:

<h2>🛠️ Construído com</h2>

* Python

* HTML
  
* Flask
